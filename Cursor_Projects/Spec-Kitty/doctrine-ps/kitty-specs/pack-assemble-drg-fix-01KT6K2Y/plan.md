# Implementation Plan: Pack Assemble Fix — DRG Graph Naming + Compilation Automation

**Branch**: `overhaul/migrate_to_kitty` | **Date**: 2026-06-03 | **Spec**: [spec.md](spec.md)
**Mission**: `pack-assemble-drg-fix-01KT6K2Y`

---

## Summary

Fix the silent naming mismatch that causes `pack validate` to skip DRG validation and
`pack assemble` to drop the pack's DRG content. Deliver: a correctly-named compiled graph
file (`regnology-default.graph.yaml`), a `tools/compile-drg.py` script to regenerate it,
a CI stage in `Jenkinsfile`, a staleness guard via `Makefile` + pre-commit hook, and
`enhances:` declarations on 4 colliding artifacts to eliminate all `pack validate` advisories.

---

**Language/Version**: Python 3.x (compile script); POSIX shell/Makefile (freshness guard); Groovy (Jenkinsfile stage); YAML (pack artifacts)
**Primary Dependencies**: `specify_cli` / `doctrine` Python package (already installed via pipx spec-kitty venv); `make` (standard on Linux/macOS CI); pre-commit (already used in repo)
**Storage**: `pack/drg/regnology-default.graph.yaml` — committed artefact, regenerated by script
**Testing**: `spec-kitty doctrine pack validate pack/` exits 0 errors 0 advisories; `list(Path("pack/drg").glob("*.graph.yaml"))` non-empty
**Target Platform**: Linux CI (Jenkins); Linux/macOS developer workstations
**Project Type**: Tooling (script) + CI pipeline stage + YAML config

## Work Packages

### WP01 — Compile script + initial graph generation

Write `tools/compile-drg.py` that reads `pack/drg/fragment.yaml` via the `doctrine`
Python API and writes `pack/drg/regnology-default.graph.yaml`. Run it to produce the
initial correct file. Delete the old `pack/drg/graph.yaml`.

**Deliverables**:
- `tools/compile-drg.py` (new)
- `pack/drg/regnology-default.graph.yaml` (new — replaces graph.yaml)
- `pack/drg/graph.yaml` (deleted)

**Acceptance**: `python tools/compile-drg.py` exits 0; `list(Path("pack/drg").glob("*.graph.yaml"))` non-empty; `spec-kitty doctrine pack validate pack/` produces 0 DRG errors.

### WP02 — CI stage + staleness guard

Add `Compile DRG Graph` stage to `Jenkinsfile` before `Package`. Add `Makefile` with
`check-drg-fresh` target. Wire `check-drg-fresh` into pre-commit (`.pre-commit-config.yaml`
or `.cursor/hooks.json`) for commits touching `pack/drg/fragment.yaml`.

**Deliverables**:
- `Jenkinsfile` (modified — new stage)
- `Makefile` (new or modified)
- `.pre-commit-config.yaml` or `.cursor/hooks.json` (modified — new hook entry)

**Acceptance**: `make check-drg-fresh` exits 0 when graph is fresh; exits non-zero with clear message when fragment is newer. Jenkinsfile stage runs `python tools/compile-drg.py` before Package.

### WP03 — Pack validate advisory fixes

Add `enhances:` declarations to the 4 colliding artifacts. Verify `pack validate` exits
0 errors 0 advisories. Sync deployed pack to `_config/packs/regnology-default/`.

**Deliverables**:
- `pack/tactics/context-boundary-inference.tactic.yaml` (modified)
- `pack/tactics/secure-design-checklist.tactic.yaml` (modified)
- `pack/styleguides/java-conventions.styleguide.yaml` (modified)
- `pack/styleguides/python-conventions.styleguide.yaml` (modified)

**Acceptance**: `spec-kitty doctrine pack validate pack/` → `0 errors, 0 advisories`.
