# Gemini agent — `about.md` template

**Output-structure contract** for the `about.md` file inside each
`gemini-agents/{chatbot-slug}/` folder — `gemini-agents/` is a directory in the
separate **`regnology-ps-chatbots`** repository, not `doctrine-ps`. This file
contains the agent's display identity: the text that goes into the workspace
`name`, `description`, and `profile picture` fields when creating the agent in
Gemini Enterprise.

---

## Generation comment block (required — top of every generated file)

```
<!--
  GENERATED BY: gemini-bot-georgia
  SOURCE PROFILE: {source_profile_path | or "hand-authored; no pack profile"}
  ROSTER: gemini-agents/roster.yaml @ roster_version {roster_version}
  SOURCE DOCTRINE: {doctrine_pack} @ {doctrine_version}
  GENERATED: {generation_date}
  PURPOSE: Description and avatar to paste into the agent's profile fields when
  creating it in the Gemini Enterprise workspace. Do not hand-edit; regenerate
  from the source profile.
-->
```

---

## 1. Agent name heading (required)

```markdown
# {Agent Name}

![{Agent Name} avatar](./avatar.png)
```

---

## 2. Short description (required)

```markdown
## Short description (for the workspace "description" field)

{2–4 sentences. Covers: what the agent specialises in, the primary artefacts or
outputs it produces, and any key operational constraint (e.g. "always targets a
named reader persona", "routing only"). Brand-compliant voice: sentence case,
no exclamation, no emoji. Aim for under 60 words.}
```

---

## 3. One-liner (required)

```markdown
## One-liner (for lists and the roster)

{Single short sentence — 10 words or fewer. This is the summary that appears in
gemini-agents/roster.yaml and in the navigator subagent's catalogue. Covers the agent's
domain and primary task type only.}
```

---

## 4. Avatar (required)

```markdown
## Avatar

- File: `avatar.png`
- Style: illustrated portrait, {female|male} face matching the name "{Agent Name}",
  Regnology logo and brand palette (dark teal background, green/blue/orange gradient
  blobs) in the background. Matches the style of
  `gemini-agents/shared/branding/avatar-reference-{female|male}.png`.
- Kept under 200KB (longest side ~460px) so Gemini accepts it as an agent icon.
- Use it as the agent's profile picture when creating the agent in the workspace.
```

**Avatar generation rules:**
- Derive gender from the agent's name.
- Use `gemini-agents/shared/branding/regnology-brand-wallpaper.jpeg` for colour palette and background.
- Use `gemini-agents/shared/branding/avatar-reference-female.png` for female agents and
  `avatar-reference-male.png` for male agents — illustrated portrait style, not photorealistic.
- Longest side ~460px; verify byte size is under 200KB before saving.
