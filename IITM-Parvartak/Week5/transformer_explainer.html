Our Sample Sentence

We'll use this English sentence throughout the entire walkthrough — translating it to French:

Thetoken 1
cattoken 2
sattoken 3
ontoken 4
thetoken 5
mattoken 6
→ « Le chat s'est assis sur le tapis »

Each word is a token. In real models, subword tokenisation (BPE) may split "sitting" → "sit" + "##ting". For clarity we'll keep whole words. The model never sees characters — only integer IDs like [4182, 7291, 3841, 512, 4182, 9931]

01

Token Embedding Input Layer

Each token ID is looked up in a learned embedding table — a giant matrix of shape [vocab_size × d_model]. Each word becomes a dense vector of numbers that capture semantic meaning.

embedding("cat") → [0.21, -0.84, 0.03, 0.67, ... ] ← 512 numbers

Visualised embeddings (each column = one token, rows = dimensions, color intensity = value)

🗂
"The" → ID 4182 → Row 4182 of the embedding matrix Result: a 512-dimensional vector. Similar words (cat, dog, kitten) end up close together in this 512-D space.
🧠
Embeddings are LEARNED during training The model adjusts these 512 numbers via backpropagation until semantically similar words cluster together. "king" − "man" + "woman" ≈ "queen"
02

Positional Encoding Order Signal

Attention is order-agnostic — it treats all tokens as a bag. We must inject position information. A fixed sine/cosine pattern is added to each embedding.

PE(pos, 2i) = sin(pos / 10000^(2i / d_model)) PE(pos, 2i+1) = cos(pos / 10000^(2i / d_model))

Positional encoding heatmap — rows = tokens (The/cat/sat/on/the/mat), columns = dimensions

📍
"cat" (pos 2) gets a DIFFERENT pattern than "the" (pos 1) Even if two tokens are identical words (both "the" in our sentence), they get different positional offsets, so the model knows position 1 ≠ position 5.
🌊
Why sine waves? They generalise to unseen lengths The model trained on sentences up to length 128 can still process length 200 — the waves simply continue. This is better than learned position embeddings for long inputs.
03

Attention: Q, K, V Core Mechanism

This is the heart of the Transformer. Each token asks: "which other tokens should I pay attention to?" It does this via three learned projections:

🔍 QUERY (Q)

"What am I looking for?"

Token "cat" broadcasts its question to all other tokens

🗝 KEY (K)

"What do I offer?"

Each token advertises itself — does it match Q?

📦 VALUE (V)

"What info do I share?"

Actual content retrieved if attention is high

Attention(Q, K, V) = softmax( Q·Kᵀ / √d_k ) · V
1️⃣
Score: Q · Kᵀ Dot product between "cat"'s query and every token's key → raw score. High score = relevant. "cat" scores 8.2 against "sat", 1.1 against "the"
2️⃣
Scale by √d_k Prevents scores from getting too large when d_k is big (large dot products → softmax vanishing gradient). With d_k=64, divide by 8.
3️⃣
Softmax → attention weights (sum to 1) Converts raw scores to probabilities. [0.05, 0.62, 0.25, 0.03, 0.03, 0.02] — "cat" mostly attends to itself and "sat".
4️⃣
Weighted sum of Values Multiply each Value vector by its weight and sum. "cat"'s new representation is a blend of all tokens, weighted by relevance.

05

Multi-Head Attention 8 Perspectives

Instead of one attention pass, the model runs 8 parallel heads — each with its own Q/K/V weight matrices. Each head specialises in a different type of relationship.

HEAD 1
Syntactic subject

Learns which noun is the subject. "cat" → "sat" (who does the action)

HEAD 2
Article-Noun binding

"The" → "cat", "the" → "mat" (determiners find their nouns)

HEAD 3
Prepositional phrase

"on" attends strongly to "mat" (preposition-object)

HEAD 4
Local context

Each token attends to immediate neighbours — bigram patterns

HEAD 5
Long-range deps.

"mat" attends back to "cat" (what is on the mat?)

HEAD 6
Coreference

Links pronouns & repeated nouns to their referents

HEAD 7
Semantic roles

Identifies agent/patient roles across the sentence

HEAD 8
Global context

Every token attends to [CLS] token — sentence-level meaning

All 8 head outputs (each of size d_k=64) are concatenated → vector of 512 → passed through one final linear layer W_O. This gives the model 8× the representational power of single-head attention.

MultiHead(Q,K,V) = Concat(head₁,...,head₈) · W_O where headᵢ = Attention(Q·Wᵢ_Q, K·Wᵢ_K, V·Wᵢ_V)
06

Causal Mask Decoder Only

In the decoder, when generating the French translation, token position 3 must NOT see positions 4, 5, 6 — they don't exist yet! A triangular mask fills future positions with −∞ before softmax (which makes them → 0).

French output so far: Le / chat / s'est / assis / sur — generating "le":

■ Can attend    ■ Blocked (future token — masked to −∞)

07

FFN + Residual + LayerNorm Per-Token Processing

After attention, each token's vector passes through a position-wise Feed-Forward Network — independently, with shared weights. Then a residual skip-connection and layer normalisation are applied.

⚡
FFN: d_model → 4× expansion → d_model Two linear layers with ReLU: FFN(x) = ReLU(x·W₁ + b₁)·W₂ + b₂. Expands 512 → 2048 then back. This stores "factual knowledge" — models like GPT store facts about the world in FFN weights!
➕
Residual Connection: output = x + sublayer(x) The original input bypasses each sublayer and is added back. This lets gradients flow easily during training (solves vanishing gradient) and preserves original info.
📊
Layer Normalisation: stabilises training Normalises each token vector to mean=0, std=1, then applies learned scale (γ) and shift (β). Applied after the residual add. Without this, deep networks diverge.
08

Encoder vs Decoder Two Stacks

A full Transformer (e.g. the original machine translation model) has N=6 encoder layers stacked on top of each other, plus N=6 decoder layers.

ENCODER Reads source

  • Processes ALL tokens simultaneously (bidirectional)
  • Self-attention: every token sees every other token
  • No mask — full context available
  • Output: contextualised representations for each token
  • Used in: BERT, RoBERTa (encoder-only)

DECODER Generates target

  • Generates tokens one-by-one (left to right)
  • Masked self-attention: can only see past tokens
  • Cross-attention: Q from decoder, K/V from encoder
  • Cross-attention = where the "translation" happens
  • Used in: GPT (decoder-only), T5, original Transformer
Cross-Attention: the bridge between languages

When generating the French word "chat" (step 2), the decoder's cross-attention has:
Q = current French context ("Le …")  |  K, V = all English encoder outputs.
It learns to align "chat" ↔ "cat" purely from training data — no alignment table needed!

09

Full Pipeline: "The cat sat on the mat" → French

Let's trace every step from raw text to "Le chat s'est assis sur le tapis":

1
Tokenise source Split English input into token IDs ["The","cat","sat","on","the","mat"] → [4182, 7291, 3841, 512, 4182, 9931]
2
Embed + Positional Encode Each ID → 512-D vector; add sinusoidal position signal x = Embedding(token_ids) + PE(positions) → shape [6 × 512]
3
Pass through 6 Encoder layers Self-attention + FFN × 6. Each layer refines contextual meaning. enc₁ → enc₂ → ... → enc₆ → enc_output [6 × 512]
4
Decoder receives [START] token The decoder starts with a special <BOS> token to kick off generation tgt = [<BOS>] → embed → shape [1 × 512]
5
Decoder: Masked Self-Attention Decoder attends to its own past outputs with causal mask Generating "Le": only sees [<BOS>] — mask blocks future
6
Decoder: Cross-Attention to Encoder Q from decoder current state; K, V from encoder output. This is where alignment happens. Q=[<BOS> state], K/V=[enc_output] → attends to "The"
7
Linear + Softmax → probability over vocabulary Project 512-D output to vocab_size (e.g. 32,000), then softmax argmax(softmax(W_out · dec_output)) → "Le" (prob 0.94)
8
Repeat until [EOS] token Feed output back as next decoder input. Repeat steps 5-7. Le → chat → s'est → assis → sur → le → tapis → <EOS>
