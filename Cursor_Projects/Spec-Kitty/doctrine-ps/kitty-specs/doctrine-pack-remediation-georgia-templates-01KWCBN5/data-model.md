# Data Model: Doctrine pack remediation & Georgia templates

**Mission:** `doctrine-pack-remediation-georgia-templates-01KWCBN5`
**Date:** 2026-06-30

No application database. The "entities" here are doctrine-pack structures and their
integrity relationships. This model captures the fields/relationships the mission must
keep consistent.

## Entities

### DoctrineArtefact
- **Fields:** `id` (or `profile-id` for agent profiles), `schema_version`/`schema-version`, kind (directive/tactic/paradigm/procedure/styleguide/toolguide/agent_profile/template), `body_path`
- **Rules:** filename `*.kind.yaml`; carries Regnology branding header; registered in DRG (unless intentionally excluded) and hashed in MANIFEST.
- **Canonical shapes (FR-009, non-breaking):** paradigms use one-line `summary` + full `body`; agent profiles use a uniform `context-sources` shape (documented allowed sub-keys). Profile field naming convention (hyphen) documented as-is.

### DRG (fragment + compiled graph)
- **fragment.yaml (source):** `nodes[]` (`id`, `kind`, `title`, `body_path`) and `edges[]` (`source`, `target`, `relation`). NEW: `external_nodes[]` declaring upstream/built-in IDs with provenance.
- **graph.yaml (compiled):** generated by `spec-kitty doctrine regenerate-graph`; nodes carry typed `urn: <kind>:<id>`; edges carry typed `source`/`target` URNs.
- **Invariants:** every edge endpoint resolves to a local node OR a declared external node; no self-referencing edges; no duplicate edges; compiled kind prefixes match each target's true kind.

### MANIFEST (pack/META/MANIFEST.yml)
- **Form:** `sha256␠␠./relative/path` per line.
- **Invariant:** one current entry per on-disk pack artefact (SC-001).

### GeminiTemplateFamily (NEW — pack/templates/gemini/)
- **Members:** `instructions.md` scaffold, `about.md` scaffold, `set-up-guide.md` scaffold, `review-submission.md` scaffold, `roster.schema.yaml`, `agent-folder-layout.md`.
- **Relationship:** `gemini-bot-georgia.agent.yaml` *references* these (single source of output structure); `gemini-agents/README.md` points at them; generated `gemini-agents/<slug>/` instances conform to them.
- **Rule (C-001):** templates describe the Gemini chatbot output surface only; never cross into `pack/agent_profiles/` semantics.

## Key relationships / integrity edges

- DoctrineArtefact ⟶ DRG node (1:1, unless declared external or intentionally excluded).
- DoctrineArtefact ⟶ MANIFEST entry (1:1).
- fragment.yaml ⟶ graph.yaml (generated; must stay fresh per `regenerate-graph --check`).
- gemini-bot-georgia ⟶ GeminiTemplateFamily (references, not inlines).
- Duplicated-rule artefacts ⟶ single authoritative artefact (others reference) (FR-010).
