# Contracts

This mission (`doctrine-ps-structural-alignment-01KWVM5C`) does not introduce or modify any
API, data, or service contracts. It corrects documentation drift and ships a lint tool; there
is no contract surface to define here. This directory exists to satisfy the Software Dev Kitty
mission-type's `deliverables` path convention (`contracts/`), which the installed spec-kitty
CLI resolves against this mission's `kitty-specs/<slug>/` feature directory because
`contracts/` is listed under `mission.yaml`'s `artifacts.optional` for the `software-dev`
mission type (see `specify_cli.validators.paths.validate_mission_paths`).
